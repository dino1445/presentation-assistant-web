L1

Level 1 — Identify the Recurring Task

Recurring Task

Preparing presentations for class assignments.

The Agent helps the student understand the instructor's requirements, identify the main topic, research relevant information, create PowerPoint slides, and prepare for the presentation.

Agent Role

Presentation Assistant

Acts as a dedicated academic co-pilot throughout assignment preparation.

Goal

Turn an instructor's assignment into a clear, well-supported presentation that the student can review and approve.

Ensures zero fabrication and strictly verified citations.

L2

Level 2 — Define the Job and Its Requirements

Job Definition

When given a topic and assignment from an instructor, the Agent interprets the requirements, identifies the main focus, finds and selects relevant information, creates concise PowerPoint slides, checks their quality, and asks the student to review the slide layout before considering the work complete.

Inputs
  • The topic and instructions from the instructor
  • Lecture materials, recordings, notes, and marked passages from the textbook
  • Relevant information and statistics from the internet
Outputs
  • A PowerPoint presentation with references
  • Clear, easy-to-follow slides
  • A draft layout for the student to review and approve
Slide Requirements
  • One main idea per slide
  • About 10–20 words per slide, with a maximum of 20 words based on the student's preference
  • Uncluttered layouts
  • Readable charts and relevant images
  • Sources provided for factual claims and statistics

L4

Level 4 — Create the Hermes Agent Profile

Hermes Profile & Agent Name
presentation-assistant
Agent name: Presentation Assistant

The profile includes the job goal, inputs, outputs, workflow, quality standards, self-checks, exception handling, and limitations.

Strict Academic Integrity Guardrails

The profile tells the Agent to:

Follow the workflow defined in Levels 2 and 3.
Check sources and statistics before using them.
Check slide length, layout, charts, and images before requesting approval.
Ask the student when the assignment is unclear or the evidence is insufficient.
Strict Prohibitions & Limitations
  • Never invent statistics, sources, or quotations.
  • Never claim it searched or checked something unless it actually did.
  • Never finalize a presentation before the student approves the layout.
L5

Level 5 — Presentation Assistant Tool Connection and Test Run

Tools Connected

Hermes AI Core, Student Learning Management System (LMS) or direct chat platform, Academic databases and reliable internet search APIs (e.g., Google Scholar API, public source indices), and PowerPoint generation API.

How it works

Students submit assignments and topics via the [Student Platform]. The Agent (using [Hermes]) first identifies and refines requirements (following Levels 2 and 3 workflow). It then uses the [Search APIs] to find and verify credible sources (referencing Level 3 checks) and organizes points. A draft presentation with references is generated using the [PowerPoint API], strictly following Level 2 slide standards (one main idea per slide, 10-20 words, max 20). The Agent provides a preview link for student layout and content review (the ‘Ask AI to check’ step from Level 3 is integrated here). Following explicit student approval (Level 4 limitation), the final PowerPoint file is generated and delivered via the [Student Platform].

Test run results

The Presentation Assistant has been tested with various assignment topics from different academic disciplines (e.g., history debate, science review). The tests confirm the agent's ability to:

  • Accurately interpret complex requirements
  • Identify and verify credible sources without fabrication
  • Construct presentations with appropriate charts and imagery
  • Integrated AI self-checks for word count and layout readability function correctly
Limitations
  • The Agent relies on text-based assignments and topics for input.
  • Initial generation does not include complex real-time simultaneous editing.
  • Automated credibility checks are limited to recognized academic and authoritative online sources.
  • Source checks should still be manually reviewed for very niche topics. User approval (Level 4) is essential for layout and content before final delivery.
